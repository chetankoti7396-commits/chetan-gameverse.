# Chetan GameVerse

A free static browser-game website built with HTML, CSS, and JavaScript.

## Games
- Snake
- Tic-Tac-Toe (computer or two-player mode)
- Memory Match
- Neon Racing

## Run locally
Open `index.html` in a modern browser. The games are self-contained pages and do not need a server.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Open your GitHub repository.
3. Upload the **contents** of the extracted `chetan-gameverse` folder to the repository root (upload `index.html`, `style.css`, `script.js`, `README.md`, and the `games` folder; do not upload only the ZIP).
4. Commit changes to `main`.
5. Go to Settings → Pages and select `Deploy from a branch`, branch `main`, folder `/(root)`.
6. Wait for the Pages deployment to finish, then use the published link shown in Settings → Pages.

All game code is included in the HTML files. No paid services, logins, or external APIs are required.
